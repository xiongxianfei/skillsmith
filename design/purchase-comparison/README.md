# Purchase comparison design

See the [architecture overview](02-layered-components.md) for the decision-framework-first workflow, with optional product comparison. The [skill instructions](../../skills/purchase-comparison/SKILL.md) own operational behavior.

The accepted guidance policy recommends **both attribute importance weights and option suitability scores**, with contextual reasons and assumptions. Suggested values remain distinct from user-provided or adopted preferences. A personalized framework is a complete outcome without named products. The instructions now reflect this policy; documentation alignment is not independent approval or evidence of model compliance. Return to the [design index](../README.md).
