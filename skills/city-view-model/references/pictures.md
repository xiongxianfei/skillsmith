# Pictures for each view

Draw each view as the picture type that fits its data, and generate every picture from the tables so they never disagree.

| View | Picture | Tool |
|---|---|---|
| Place | Cards or checklist: name, score stars, priority color | Canva, PowerPoint |
| Taste | Food board: item, type label, season tag | Canva, PowerPoint |
| Space | Map with pins colored by priority | Google My Maps (import the sheet) |
| Time | Month strip or line chart; season bars for fruit | Excel chart |
| Culture | Network or mind map: themes in the center, places and food around them | PowerPoint, Canva, mind-map tool |
| Scenarios | Timeline or day cards | PowerPoint, Canva |

Rule of thumb: data to act on (tick, sort, filter) -> table. Data to understand at a glance (where, when, how connected) -> picture.

## One-page layout
- Top: city name, one-line intro, best time to visit
- Middle: Place and Taste checklists side by side, tourist map below
- Lower: Time strip and Culture links
- Bottom: Scenario day cards

## Consistency
- Same color means the same thing everywhere (Must red, Nice amber, Optional gray).
- Same names as in the tables.
- One idea per picture, with a short title.
- Pictures are working files; copy finished ones to the published folder.
