# Mouse: attributes and options (no scores)

Edit freely. The user scores each option and sets each weight. Ask for hand length, hand width, grip (palm, claw, fingertip, hybrid) and usage mix first, because size and shape options depend on them.

| Attribute | Options |
|---|---|
| Length | Ranges, for example <118 / 118-121 / 122-128 / >128 mm (adjust to hand size) |
| Width | <62 / 62-66 / >66 mm |
| Height | <=37 / 38-39 / 40-42 / >42 mm |
| Weight | <50 / 50-60 / 61-70 / 71-80 / >80 g |
| Shape | Symmetrical / Ergonomic right-handed / Ergonomic left-handed |
| Hump position | Rear / Middle / Front |
| Side grip | Smooth / Light texture / Grooves or rubber panels |
| Click feel and switch type | Light and crisp (optical) / Light and crisp (mechanical) / Medium / Heavy or mushy |
| Click force | <55 gf / 55-70 gf / >70 gf |
| Sensor | Current flagship / Mid-range / Older |
| Connection | Wired / 2.4 GHz / Bluetooth / 2.4 GHz + Bluetooth |
| Polling rate | <=1000 Hz / 2000-4000 Hz / 8000 Hz |
| Battery | <60 h / 60-100 h / >100 h (blank for wired) |
| Material | Matte plastic / Coated / Rubberised |
| Price | Ranges set by the user's budget |
| Reviews | Rating bands plus a minimum review count |

Notes: dimensions are only a first filter. Final fit depends on hump position and side curvature, so recommend hands-on testing where possible.
