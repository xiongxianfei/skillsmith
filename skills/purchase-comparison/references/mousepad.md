# Mousepad: attributes and options (no scores)

Edit freely. The user scores each option and sets each weight. Ask about the mouse (weight, feet material), desk space, and whether play is mostly flicks or tracking.

| Attribute | Options |
|---|---|
| Surface type | Speed (smooth) / Balanced / Control (textured) |
| Size | Small (<=300 mm wide) / Medium (300-400) / Large (400-500) / Extended desk mat (>500) |
| Thickness | <=2 mm / 3 mm / 4 mm / >4 mm |
| Base | Rubber non-slip / Cloth / Hard or glass surface |
| Edge | Stitched / Unstitched |
| Material | Cloth / Hard plastic / Glass / Hybrid |
| Washability | Washable / Wipe-clean only / Not washable |
| Wrist support | Padded edge / None |
| Durability | Reputation for lasting >2 years / Unknown / Known to wear quickly |
| Price | Ranges set by the user's budget |
| Reviews | Rating bands plus a minimum review count |

Notes: surface feel depends on the mouse's feet and the user's sensitivity setting, so feel is only partly predictable from specs.
